# Erimentha — Controls

| Action | Controller |
|--------|------------|
| Move | Left stick |
| Attack | West button (X) |
| Dodge | East button (B) |
| Switch weapon | North button (Y) |
| Interact / Confirm | South button (A) |
| Navigate menus | D-pad |
| Back / Cancel | East button (B) |
| Pause | Start |

---

## Combat Tips

- **Sword** — fast swing, 40% movement while attacking, light knockback.
- **Axe** — slow swing, stops movement completely, heavy knockback and damage.
- **Dodge** grants full invincibility for its duration.
- You have **1 second of invincibility** after being hit — use it to reposition.
- Attacks have an **input buffer**: pressing attack slightly early queues a follow-up swing.

---

## Town Interactions

Press **E / A** to talk to any named NPC. An indicator at the top of the screen shows who is in range.

| NPC | Role |
|-----|------|
| **Innkeeper** | Sleep to end the day; browse a shop |
| **Blacksmith** | Buy the axe (50 Scripts); upgrade weapons |
| **Guild Commander** | Accept bounties; turn in contracts for Scripts |
| **Bounty Board** | Browse and accept contracts |
